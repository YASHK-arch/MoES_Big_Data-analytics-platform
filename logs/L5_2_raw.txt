--- 7. GAPS IDENTIFIED ---
  a) Devanagari script: NOT supported. Resolver uses ASCII lowercase matching.
     Hinglish variants (Dilli, Bambai): NOT in gazetteer.
  b) Many neighbouring countries/capitals missing from FOREIGN_LOCATIONS:
     MISSING: Pakistan / Islamabad / Karachi / Lahore
     MISSING: China / Beijing / Kunming (shares border with India)
     MISSING: Myanmar / Naypyidaw / Yangon
     MISSING: Afghanistan / Kabul
     MISSING: Bhutan / Thimphu
     MISSING: Maldives / Male
  c) Germany/Berlin in gazetteer — likely test artifact; retained as-is.
  d) Multi-place: resolver returns FIRST matched entity. For mismatch detection,
     we need ALL entities to check if declared state is among them (P2).
     The existing resolver.resolve() only returns ONE result.
     The extractor.extract_entities() returns ALL — we will use the extractor directly.
  e) Ambiguous places (Rajpur, Bilaspur, Rampur, Aurangabad): resolver returns
     AMBIGUOUS status with confidence=0.0 when no context disambiguates.
     For mismatch detection, ambiguous -> NEUTRAL (P1 applies).
